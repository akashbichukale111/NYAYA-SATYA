# Domain Model

See `backend/app/models/orm.py` for the authoritative, always-up-to-date
source. Summary:

| Entity | Purpose |
|---|---|
| Case | Top-level container; all other entities are scoped to a case_id. |
| Person | The undertrial person in a case. |
| Document | An uploaded source file with hash, MIME, extraction status. |
| CustodyEvent | A discrete custody-related event (arrest, remand, transfer, etc.) |
| Hearing | A scheduled or held court hearing. |
| Order | A court order, optionally linked to a hearing. |
| BailEvent | Bail application/hearing/order tracking, without outcome prediction. |
| ReleaseRelatedEvent | Release-related records, with an explicit `current_status_confidence` field so a reported release is never silently treated as "currently free". |
| FilingEvent, LegalAidEvent, ProceduralEvent, EvidenceItem, DeadlineRecord | Supporting procedural records. |
| Dependency | An edge in the case's dependency graph, with provenance. |
| AttentionItem | An operational attention signal generated by the Attention Engine. |
| Conflict | A detected disagreement between two sources, resolved only by a human. |
| Verification | A recorded verification decision against an entity. |
| ReviewTask | A pending/approved/rejected human review item. |
| CaseSnapshot | An immutable point-in-time copy of the Digital Twin, for the Time Machine. |
| AuditEvent | An append-only log entry for any create/update/approve/reject/simulate action. |
| ProvenanceRecord | A standalone provenance ledger entry when independent audit history is needed. |
| User | An authenticated actor with a role (CITIZEN/LEGAL_AID/ADVOCATE/ADMIN). |

Every entity that can originate from a document carries `source_document_id`,
`source_page`, `source_section`, `source_text_snippet`, and
`extraction_method` (via `ProvenanceMixin`). Fields left null are rendered as
"SOURCE LOCATION UNKNOWN" by the API/frontend — never fabricated.

## Controlled vocabularies

All status/type fields use the enums in `app/core/enums.py` rather than raw
strings, e.g. `CustodyEventType`, `HearingStatus`, `OrderStatus`,
`BailEventType`, `ReleaseEventType`, `AttentionCategory`, `SignalSeverity`,
`DependencyType`, `ReviewTaskType`, `UserRole`, `AuditAction`. See that file
for the full, current list.

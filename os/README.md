### Unified Legal Case Intelligence Platform

> **"Built for one case. Architected for every jurisdiction."**

## What is NYAYA-SATYA OS?

NYAYA-SATYA OS unifies **12 specialized legal intelligence engines** into a single cohesive operating system shell, serving high-stakes legal case analysis, procedural scrutiny, liberty protection, and practice automation.

## Quick Start

### 1. Launch Unified OS
From PowerShell:
```powershell
cd D:\NYAYA-SATYA\os
.\run_os.ps1
```
Or from Command Prompt:
```cmd
cd D:\NYAYA-SATYA\os
run_os.bat
```

Open your browser to:
**`http://127.0.0.1:8000`**

### 2. Run Comprehensive Integration Tests
```powershell
$env:PYTHONPATH='D:\NYAYA-SATYA\os'
D:\NYAYA-SATYA\unwind-live-verified-main\.venv\Scripts\python.exe -m pytest D:\NYAYA-SATYA\os\tests\test_os_integration.py -v
```

## Core Invariants

1. **Non-Adjudication Guarantee**: Zero judicial outcome prediction. No probabilities assigned to judicial decisions.
2. **UNWIND Human Legal Gate**: All consequential actions require licensed advocate authorization (`AWAITING_AUTHORISATION`).
3. **Multi-Tenant Case Isolation**: Strict partitioning of evidence, claims, obligations, and deadlines by `case_id`.
